## 🎯 Objetivo

- Praticar lógica de programação e resolução de problemas.
- Comparar diferentes abordagens para o mesmo problema (`for`, `while`, `do while`, funções, recursão).
- Registrar a evolução ao longo da disciplina.
- Servir como material de consulta e revisão.

---

## 🧠 Conteúdos abordados

| Tema | O que foi praticado |
|------|---------------------|
| Fundamentos | Variáveis, tipos de dados, entrada e saída, operadores e expressões |
| Estruturas condicionais | `if`, `else`, `switch`, menus interativos |
| Estruturas de repetição | `for`, `while`, `do while`, uso de flag, contadores e acumuladores |
| Funções | Modularização, parâmetros e retorno de valores |
| Recursão | Versões recursivas e iterativas dos mesmos problemas |
| Ponteiros | Passagem de parâmetros por referência |
| Vetores | Troca, deslocamento e busca de valores em posições |
| Arquivos | Leitura de dados e processamento a partir de arquivos |

##🚀 Como executar os projetos
1- Clone o repositório ou baixe os arquivos pelo GitHub.
2- Abra a pasta do exercício que deseja executar.
3- Compile o arquivo .c utilizando um compilador C, como o GCC:
   gcc arquivo.c -o programa

4-Execute o programa pelo terminal:

  -Linux/macOS:

     ./programa


  -Windows:

     .\programa.exe


Observação: substitua arquivo.c pelo nome do arquivo desejado. Cada exercício pode ser compilado e executado individualmente. Certifique-se de ter um compilador C instalado.
